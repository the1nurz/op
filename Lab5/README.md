# Лабораторна робота №5

Розробка багатовіконного інтерфейсу користувача для графічного редактора об’єктів.
Варіант №27, C++17, WinAPI та GDI. Основа — `../Lab4`, її файли не змінено.

## Можливості

- Singleton Меєрса: `MyEditor::Instance()` містить локальний статичний об’єкт.
  Конструктор і деструктор приватні, копіювання й присвоювання заборонені.
- Шість фігур, кольори, незаповнені контури, множинне та віртуальне
  успадкування, пунктирне прев’ю, меню, Toolbar і підказки з Lab4.
- Окремий немодальний діалог `MyTable` з ListView, створений `CreateDialogParamW`.
  Пункт «Таблиця об’єктів» відкриває/закриває єдину таблицю.
  Головне вікно залишається доступним. Tab і Escape обробляє `IsDialogMessageW`.
- Таблиця показує номер, тип і координати. Додавання, видалення та завантаження
  автоматично оновлюють її. Вихід закриває обидва вікна.
- Вибір рядка виділяє фігуру синьою пунктирною рамкою; її власний стиль не змінюється.
- Кнопка «Видалити вибране» або Delete у списку видаляє об’єкт і звільняє пам’ять.
- «Файл → Зберегти...» та «Файл → Відкрити...» працюють з усіма шістьма типами.
  Перед заміною непорожнього малюнка програма запитує підтвердження.

## Запуск у Visual Studio

Потрібні Visual Studio з **Desktop development with C++**, Windows SDK і CMake.

1. Вибрати **File → Open → Folder**, відкрити саме папку `Lab5`.
2. Дочекатися конфігурації CMake, вибрати `x64-Debug`.
3. Вибрати `Lab5.exe` як Startup Item, натиснути `Ctrl+F5` або `F5`.

Окремий `.sln` не потрібен. Приклад для Developer PowerShell і VS 2022:

```powershell
cmake -S Lab5 -B Lab5/out/vs -G "Visual Studio 17 2022" -A x64 -DLAB5_BUILD_TESTS=ON
cmake --build Lab5/out/vs --config Debug
ctest --test-dir Lab5/out/vs -C Debug --output-on-failure
.\Lab5\out\vs\Debug\Lab5.exe
```

Для іншої версії Visual Studio вибрати відповідний генератор з `cmake --help`.
MSVC у цьому середовищі відсутній; фактично перевірено MinGW UCRT64.

## Перевірене збирання MinGW

Команди з кореня репозиторію:

```powershell
$env:PATH = 'C:\msys64\ucrt64\bin;' + $env:PATH
cmake -S Lab5 -B Lab5/build -G "MinGW Makefiles" -DCMAKE_BUILD_TYPE=Debug -DLAB5_BUILD_TESTS=ON -DCMAKE_CXX_COMPILER=C:/msys64/ucrt64/bin/g++.exe -DCMAKE_RC_COMPILER=C:/msys64/ucrt64/bin/windres.exe -DCMAKE_MAKE_PROGRAM=C:/msys64/ucrt64/bin/mingw32-make.exe
cmake --build Lab5/build --parallel 4
ctest --test-dir Lab5/build --output-on-failure
.\Lab5\build\Lab5.exe
```

## Користування

Вибрати інструмент у меню «Об’єкти» або на Toolbar. На полотні натиснути ліву
кнопку миші, перетягнути та відпустити. Для крапки достатньо клацання. Еліпс
задається центром і кутом рамки, як у Lab4. Межа — 128 завершених об’єктів.
Для демонстрації відкрити `docs/example.txt`, потім «Таблиця об’єктів».
Вибрати рядок для виділення або натиснути кнопку видалення.

Зберігати роботу потрібно через меню «Файл» перед виходом. Завантаження замінює
набір об’єктів лише після успішної перевірки всього файлу. Скасування діалогу
чи помилка читання не змінює поточний малюнок.

## Формат файлу

```text
LAB5 1 2
11 100 150 300 200
15 400 200 500 300
```

Заголовок: маркер, версія, кількість. Далі: `type x1 y1 x2 y2`.
ID: 10 — крапка, 11 — лінія, 12 — прямокутник, 13 — еліпс,
14 — лінія з кружечками, 15 — куб. Координати цілі, від −1000000 до 1000000.
Відхиляються невідомі типи, зайві дані, неповні записи, понад 128 об’єктів,
непідтримувана версія й файли понад 64 КіБ. Порядок фігур зберігається.
Запис: тимчасовий файл у цільовій папці, перевірка WriteFile/FlushFileBuffers/CloseHandle,
потім MoveFileExW. При помилці заміни попередній файл залишається на місці.

## Структура та розширення

- `src/Shape*`, шість класів фігур, `GdiGuards.h` — основа з Lab4; додано TypeId і Bounds.
- `src/ShapeFactory.h/.cpp` — каталог типів, назв, піктограм і фабрик.
- `src/MyEditor.h/.cpp` — Singleton, масив, вибір, видалення, файлові операції.
- `src/MyTable.h/.cpp` — незалежний діалог, значення TableRow і callback.
- `src/MainWindow.h/.cpp`, `src/main.cpp` — головне вікно, зв’язування модулів і цикл повідомлень.
- `resources/` — bitmap із Lab4, ID і шаблон ресурсу діалогу.
- `tests/` — три автоматичні перевірки.
- `docs/` — UML (`.mmd` і `.png`), приклад файлу, протокол і справжні скріншоти.
- `Звіт/` — повний редагований звіт українською в DOCX, Markdown та HTML.
- `tools/make_report.py` — повторна генерація звіту та PNG UML (Python, Pillow).
- `tools/make_docx_reports.py` — перетворення готових Markdown-звітів Lab4 і Lab5
  у DOCX зі збереженням усіх текстів коду та вбудованими UML і скріншотами
  (Python, python-docx, Pillow).

Для нового типу додати клас із Show, TypeId і за потреби Bounds, зареєструвати
його у ShapeFactory, додати піктограму до ресурсів і `.cpp` до CMake.
Цикли редактора, серіалізація, таблиця та обробка інструментів не змінюються.
MyTable не включає заголовки редактора або фігур: він викликає функцію
`Callback(void*, Event, int)`, а MainWindow вирішує, що робити з подією.

`build`, `tmp`, `out` і `.vs` виключені з Git.
