## Збірка та повторні перевірки

Новий каталог `.work/audit-lab2/build` створено чистою CMake-конфігурацією Debug з `CMAKE_CXX_STANDARD=17`, `CMAKE_CXX_STANDARD_REQUIRED=ON`, `CMAKE_CXX_EXTENSIONS=OFF`, `LAB2_BUILD_TESTS=ON`. GCC 16.2.0 зібрав два виконувані файли з `-std=c++17 -Wall -Wextra -Wpedantic`. Compiler warning 0, compiler error 0. Після коригування тесту та прибирання пробілів збірку повторено. Фінальний CTest пройшов 1/1 за 0.12 с.

Проміжна повторна збірка завершилася помилкою `cannot open output file Lab2.exe: Permission denied`, оскільки саме цей файл був відкритий GUI-перевіркою. Після штатного Файл → Вихід повторне компонування завершилося успішно. Початковий git add повідомив про перетворення LF у CRLF для CMakeLists.txt. Це попередження Git про формат рядків, компілятор попереджень не видав.

Незалежна тимчасова перевірка включає фактичний main.cpp та реальні модулі. Вона відтворює Windows-повідомлення для кожної фігури в чотирьох напрямках, перевіряє від’ємні координати, скасування capture, 127 успішних додавань та відмову при 128-му. У цьому автоматичному прогоні MessageBoxW замінено лічильником викликів. Відстеження C++ new/new[] і delete/delete[] зареєструвало 129 виділень та 0 активних після завершення. Це вимірювання звичайного життєвого циклу програми, включно зі скасуванням чернетки. Внутрішні алокації самої Windows не перехоплювалися. Після прогрівання 34 000 Draw дали незмінний лічильник GDI 6 → 6.

У реальному GUI чистої збірки мишею створено крапку, лінію, прямокутник та еліпс. Перевірено заголовок кожного інструмента, усі меню, діалог довідки, зміну розміру, згортання, відновлення і штатний вихід. Прямокутник вводиться від центра та має рожеве заповнення, еліпс за кутами має прозору середину. Пунктир preview підтверджено кодом обробки руху та перевіркою чорних/білих GDI-пікселів, окремий кадр середини перетягування не отримано. Ручне введення 127 фігур не дублювали, межу перевірено повідомленнями через справжню WindowProc.

Локальні протоколи збережено в `.work/audit-lab2/` і виключено з Git. Це configure.log, build.log, rebuild-final.log, ctest-final.log, memory_probe.cpp, memory_probe-final.log, method-pages7-11.txt та рендери DOCX. Тимчасові бібліотеки, executables і кеші складання не входять до коміту.

У ньому титульна сторінка за зразком Lab1, тема і мета, Ж=27, опис програми і класів, PNG-діаграма успадкування, повний main.cpp та власні модулі, CMakeLists.txt, два реальні скріншоти, результати перевірки, п’ять контрольних відповідей і висновки. Перевірка python-docx і ZIP пройшла. Кожен із 12 основних лістингів текстово збігається з фактичним файлом. У документі три зображення — діаграма і два скріншоти.

Канонічний render_docx.py створив 10 сторінок. Візуально перевірено всі сторінки. Після виправлення перенесення відповідей повторно перевірено сторінки 9–10 та ідентичність зображень попередніх восьми сторінок. Після синхронізації пробільних рядків виконано завершальний рендер та порівняння з уже переглянутою версією. Порожніх сторінок, обрізаних рисунків та зламаних таблиць немає. Видимих місць для майбутніх рисунків немає.

## Git та підсумок

Фінальний коміт має назву `fix(lab2): verify and finalize variant 27`, цільова гілка main з upstream origin/main. До нього входять тільки файли lab2. Lab1 звірено з базовим HEAD без розбіжностей. `.gitignore` виключає build/ та .work/, DOCX додано до індексу. Після коміту та push виконується звірення HEAD з origin/main і чистоти робочого дерева. Фактичний SHA наведено у фінальному повідомленні, щоб уникнути самопосилання всередині коміту.

Блокувальних помилок параметрів Ж=27, ООП, звичайного життєвого циклу пам’яті, збирання або складу звіту не залишилося. M01 залишається некритичним зауваженням стійкості. MSVC та fault-injection позначено NOT TESTED. Підсумок **ГОТОВА ДО ЗДАЧІ** для перевіреної Windows/MinGW-конфігурації.
