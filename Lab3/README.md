# Лабораторна робота №3 — графічний редактор

Окремий графічний редактор на C++17, WinAPI/GDI та CMake для варіанта 28. Модель зберігає до 128 фігур; панель інструментів має кнопки крапки, лінії, прямокутника та еліпса з власними піктограмами й українськими підказками.

Збирання у Windows із кореня репозиторію:

```powershell
cmake -S Lab3 -B Lab3/build
cmake --build Lab3/build --config Release
```

Поточний етап додає Toolbar, обробку tooltip-повідомлень і синхронізацію кнопок із командами меню. GUI-збірка і запуск мають бути перевірені у середовищі з Windows C++ toolchain.
